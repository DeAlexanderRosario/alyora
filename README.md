# ALYORA Real Estate

Modern property management platform built for Kerala real estate listings, backed by Expo, Node.js Express, MongoDB Atlas, and Cloudinary.

## Features
- **Frontend**: Expo Router, React Native Web, Lucide Icons
- **Backend**: Express API server with JWT Auth (`server/index.js`)
- **Database**: MongoDB Atlas (`Property`, `Location`, `Inquiry`, `Admin` models)
- **Media**: Cloudinary integration for property & location image uploads

## Getting Started

1. **Start Backend Server**:
   ```bash
   npm run server
   ```

2. **Start Frontend Web/Mobile**:
   ```bash
   npm run dev
   ```
